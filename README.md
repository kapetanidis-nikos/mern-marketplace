A full-stack MERN (**MongoDB, Express, React, Node.js**) e-commerce marketplace.

---

## 🧰 Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Authentication:** JWT
- **Deployment:**

---

## 🛠️ Installation

Follow these steps to set up the project locally:

### 1️⃣ Prerequisites

- Node.js (version 18 or higher)
- npm or yarn
- Git
- MongoDB running locally or a cloud instance

---

### 2️⃣ Install and Run Project

```bash
# Clone repository
git clone https://github.com/yourusername/your-repo-name.git

# Navigate into the project folder
cd mern-marketplace

# Run the server
cd server
npm install
npm start

# Open a new terminal, then run the client
cd client
npm install
npm run dev
```
